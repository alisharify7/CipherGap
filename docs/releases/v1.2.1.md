# CipherGap 1.2.1

Released 2026-10-04.

Recipients without CipherGap now see a short Persian explanation after each
encrypted message, with a link to https://github.com/alisharify7/CipherGap for
installation. This guide is part of the transmitted message. Enabled readers
hide it even before decryption; global or per-chat pause makes it visible again.
Bale can render it as one text block or as separate paragraphs and a link.

Chrome and Firefox use the same serializer, parser and presentation code.
Existing keys and older CGP v1 messages remain readable. Update both participants
to 1.2.1 before exchanging notice-bearing messages: earlier readers treat the
guide as part of the encrypted payload and cannot decrypt those messages.

Validation: shared encryption/protocol regressions, real Chromium tests for
notice serialization, split/nested/link rendering, manual/automatic decryption
and pause/resume; Firefox ESR content-script message, key-exchange and file
round trips; reproducible Chrome/Firefox package checks.
