# CipherGap 1.8.1 — 2026-11-22

Group management, a key lifecycle view, an optional send review and message search.
Message format v2 from 1.8.0 is unchanged, so 1.8.0 users can read 1.8.1 messages.

## Groups

- The group creator can **remove a member** or **rotate the group key** from the popup.
  Everyone else receives the new key in the chat without joining again. The removed
  member keeps the messages they already have but cannot read new ones.
- Messages sent before a rotation stay readable through previous keys, which follow the
  same forward-secrecy retention window.
- Optional member names are stored only on the creator's device.
- Group membership records and previous keys are encrypted at rest when the app lock is on.

## Interface

- **Key lifecycle:** the popup shows the key type (forward secrecy or long-lived), when
  it was saved, how far back messages are readable, and verification.
- **Review before sending (optional):** shows your message next to the ciphertext before
  each encrypted send. Off by default (Settings → Privacy & security).
- **Search:** a search button in the chat controls finds decrypted messages loaded in
  the open chat, with next/previous match. Scroll up to load older messages first.

## Notes

- The passphrase app lock remains a browser-extension feature.
- Streaming encryption for very large files was not added: the current format already
  authenticates the whole file.
