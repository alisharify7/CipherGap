# CipherGap 1.8.0 — 2026-11-22

Message format version 2, forward secrecy, self-destructing messages, an optional
app lock, secure group chats and a redesigned popup.

**Both people must update.** Version 2 messages and files cannot be read by 1.7.0
or older Android builds. Version 1 messages still open with keys that have not been
ratcheted, but not after a chat's key has been ratcheted.

## Security

- **Forward secrecy.** New chat keys advance through a daily one-way ratchet. Keys
  older than a retention window (default 7 days, 1–90 under Settings → Privacy &
  security) are deleted, so a stolen key cannot open older messages. Those messages
  become unreadable by design. Existing chats can opt in from Settings.
- **Key derivation.** HKDF-SHA256 for random keys; PBKDF2-SHA256 with 600,000
  iterations for typed passphrases.
- **Authenticated headers.** AES-GCM additional data covers the message header
  (version, timestamp, purpose) and the CGPE v2 file header (name, type, epoch).
  Messages are not bound to a chat ID because each participant's ID for the same
  conversation differs.
- **App lock (browser).** An optional passphrase (6+ characters) encrypts saved chat
  keys at rest, auto-locks after inactivity and when the browser closes, and slows
  repeated wrong guesses. A forgotten passphrase cannot be recovered; restore from an
  encrypted backup. Android does not have this lock yet.

## Features

- **Self-destructing messages.** A timer button in the chat controls: 5 minutes,
  1 hour, 24 hours, 7 days, or burn 30 seconds after the recipient opens it. Enforced
  by CipherGap on each device; it cannot stop screenshots, copies or a modified client.
- **Secure group chats.** The creator publishes an invitation from the popup; members
  join from the card in the chat and the creator approves each person. Approval
  delivers the group key sealed (ECDH + AES-GCM) to that member only. Fingerprints are
  shown on every card; approve only people you recognise. Removing a member means a new
  invitation and re-approving the others.
- **Redesigned popup.** Bottom tab bar, status hero, calmer teal design with light and
  dark themes in Persian and English.

## Fixes

- The download bridge reads the CGPE v2 header, so encrypted file previews work.
