# CipherGap v1.1.0

Released 2026-10-03.

CipherGap now has separate Security, Files, Settings and Guide pages, plus
security status and secure file controls inside Bale. Incoming encrypted files
can be downloaded and decrypted directly from their message, or automatically
when automatic receipt is enabled for that conversation.

## What's new

- A new CipherGap logo combining a conversation bubble, the letter C, a lock
  and a deliberate gap. The brand is independent of any messenger; Eitaa,
  Rubika, Telegram and WhatsApp remain planned integrations.
- A complete popup redesign with light/dark themes, keyboard navigation and
  security actions that remain visible during key verification.
- **Files → Choose secure files** opens Bale's native picker. The upload preview
  contains encrypted `.cgpe` files before you confirm sending.
- **Decrypt & download** saves the authenticated original with its original
  filename, including when Bale has already cached the encrypted attachment.
- **Files → Receive files automatically** handles new incoming attachments
  while the selected conversation is open. This option is off by default.
- Key exchange preserves your message draft. Operations stop if you change
  conversations while encryption, sending or downloading is in progress.

## Updating

Reload or reinstall the unpacked extension from the inner `CipherGap/` directory,
then refresh Bale Web in each browser profile. Existing keys, message/file
formats and per-chat settings remain compatible; no data migration is needed.
If you have installed multiple copies, enable only one copy in each profile.

Both participants need CipherGap and the same chat key. Compare the six-digit
SAS through a trusted channel and verify it on both sides. Use **Encrypt** for
private text; Bale's ordinary send button sends ordinary text.

## Validation and limits

All 22 automated tests passed, along with JavaScript syntax checks. Live testing
in two logged-in Chrome profiles confirmed ECDH/SAS verification, encrypted text
in both directions, direct cached-file decryption and automatic file receipt in
both directions. Three decrypted files matched their originals byte for byte.
Popup security states, keyboard navigation and themes were also checked in an
isolated browser. See the [browser validation record](../browser-validation.md).

- File encryption processes complete files in memory: 100 MB combined per
  selection and 100 MB per received file. Maximum-size and slow-network transfers
  were not tested live.
- Automatic receipt applies to new incoming files in the open conversation;
  history and outgoing attachments require a click.
- Direct download times out after 45 seconds. If needed, download the `.cgpe`
  through Bale and use **Choose downloaded file instead**.
- Firefox 128+ is required; this release was tested live on Chrome.
