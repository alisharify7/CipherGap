# CipherGap 1.3.0

Released 2026-10-04 for Chrome and Firefox desktop.

Received attachments now offer **Decrypt & view**. Images open in a dialog;
audio and video use native browser controls. **Download** saves the original
bytes and filename. Unsupported formats remain downloadable; active HTML/SVG
documents are never embedded. Both the native Bale attachment path and the
fallback downloaded `.cgpe` picker use the same shared authenticated file kernel.
Firefox/Linux WAV aliases are normalized for cross-browser playback.

Exchange requests can be accepted or declined directly in the chat. An existing
key requires **Replace key and accept** confirmation. A corner countdown uses
the original request deadline: 15 minutes for the request and its verification
code. At zero, the card turns gray and asks for a new exchange. Refreshing,
receiving an ACK or reopening the extension does not extend it. Expiry is checked
before sending an ACK, storing a derived key or verifying SAS. Existing saved
keys are retained when a request expires.

The extension and website share an Indigo/Slate palette from
[Radix Colors](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale).
The website selects a browser before installation steps and remembers that
choice. English remains the default, with Persian available on both products.
Messages invite recipients to install from both GitHub and the website; enabled
readers hide this footer and paused readers restore it.

## Upgrade

Update both sides to 1.3.0 before using timed exchange messages or sending the
new footer. Existing CGP/CGPE files, original crypto derivation and saved keys
are unchanged. Older messages and the 1.2.1 GitHub-only guide remain readable.
Firefox temporary installations disappear on restart; permanent releases
require Mozilla signing.

## Validation

- 30 Node regressions, including original encryption vectors, deadline checks,
  late/modified ACK rejection and absolute SAS expiry.
- Chrome and Firefox 153.4.0 installed-extension browser checks: in-chat consent,
  actual media decoding/playback, safe document fallback, original download bytes,
  footer visibility, pause, localization, cleanup and automatic receipt.
- Logged-in Firefox and Chrome ahmad on the requested Bale conversations:
  matching ECDH/SAS, verified trust, encrypted Persian text and image/audio/video
  transfer in both directions. Downloaded samples matched original bytes.
- Responsive bilingual website checks from 320 to 1440 px, fonts, installation
  tabs, persistent preferences, navigation, assets and clipboard recovery.

CGPE v1 reads and authenticates complete files in memory before playback. The
100 MB boundary, long or slow-network transfers and mobile Firefox remain
unverified. Automatic receipt is opt-in and downloads new incoming files rather
than opening a player unexpectedly. Host-page JavaScript can read content
rendered in the chat DOM; extension isolation protects crypto operations and
key storage, not plaintext displayed inside a messenger page.
