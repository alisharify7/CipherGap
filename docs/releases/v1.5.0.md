# CipherGap 1.5.0

Chat controls now use compact icon actions and surfaces that follow the native
messenger's light/dark appearance. Locked text appears as a short card rather
than a wall of ciphertext. Telegram messages keep their natural width after
decryption, delivery and resizing. Its floating toolbar mounts outside Teact's
composer so native file previews remain usable. Eitaa targets the actual body
instead of an older quoted packet and gives encrypted quotes a compact label.

Open **Emoji & stickers** in the chat toolbar. **Emoji** adds Unicode to your
draft; press **Encrypt** to send it. Joined emoji sequences, skin tones and
native image-backed Unicode emoji survive encryption/decryption.

Choose **Stickers** for a built-in PNG sticker or import PNG, JPEG, WebP, GIF,
AVIF or animated WebM, up to **5 MB**. Only encrypted `.cgst.cgpe` bytes enter the
native file preview. Confirm Send there. On receipt, **Open** authenticates and
shows the sticker inside the message. Image activation opens the larger viewer;
WebM has playback controls. **Download** preserves the original file bytes.

The sticker purpose, original filename and MIME type are inside the authenticated
CGPE body. All platforms and both browsers reuse the existing crypto kernel.
No second encryption format or service is introduced. Both participants need
**1.5.0** for inline stickers. Existing keys, text packets and regular CGPE files
remain readable. Native sticker menus and Telegram custom emoji/TGS packs are
outside the encrypted picker and remain ordinary.

Pause, chat navigation and key replacement remove decrypted views, stop playback
and release preview URLs. Pausing restores original ciphertext and installation
links. The downloaded-CGPE fallback lives under **Having trouble opening it?**.

Chrome and Firefox integration fixtures cover emoji, static/animated stickers,
exact downloads, pause, key exchange and natural message dimensions. Live checks
in the logged-in Chrome Eitaa/Telegram Saved Messages verified native ciphertext
previews, sending, text/emoji decryption and inline PNG stickers. See the
[validation record](../browser-validation.md) for the live/fixture boundaries.
