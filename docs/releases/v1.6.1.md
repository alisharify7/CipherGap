# CipherGap 1.6.1 — a cleaner Bale composer

Bale now uses the same independent security toolbar as the other desktop
messengers. Security, encrypted files, emoji/stickers, pause and encrypted send
stay above the native message box, with matching width and compact icons in
narrow windows. The toolbar stays outside the messenger’s React subtree.
Ordinary send and voice controls keep their native behavior.

The shared core is synchronized across Chrome, Firefox and Android.
Android 0.1.2 packages this core update; its supported messengers remain
Bale, Eitaa and Telegram Web A. Desktop also supports Rubika and Soroush Plus.
Encryption, key exchange and existing packet/file formats are unchanged.

## Update

Download the Chrome or Firefox ZIP from this release. Chrome: replace the
unpacked files, reload the extension, then refresh messenger tabs. Firefox:
load the updated package through `about:debugging`; permanent installs need
Mozilla signing. Android: install the 0.1.2 test APK over the previous preview
to retain local settings and sessions. It remains debug-signed.

## Checks

- 35 shared Node checks and deterministic Chrome/Firefox packaging.
- Bale Chrome: toolbar placement at 320/390/1280 px, ordinary/encrypted
  attachments, pause, text/notice rendering, media playback and exact downloads.
- Bale Firefox: two-peer key exchange/SAS, text, files, preview/playback and
  exact downloads using native DOM fixtures.
