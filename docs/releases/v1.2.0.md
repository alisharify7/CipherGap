# CipherGap 1.2.0

Released 2026-10-03.

Choose Persian or English in the popup, and use global/per-chat pause in Settings
without deleting keys. The composer offers explicit Encrypted file selection;
Bale’s normal attachment control stays unencrypted. Secure selections stop if
the conversation, key or enabled state changes.

Chrome and Firefox share all source code. Build either browser with
`python3 tools/build_extension.py --target chrome` or `--target firefox`.
Firefox uses a generated event-page manifest and supports desktop 140+.
The website branch provides bilingual setup/tutorials with local Vazirmatn and
Inter fonts. Other messengers remain a roadmap; Bale is currently active.

Validation: shared crypto/protocol regression checks, package byte identity,
Chrome fixture tests of plain/secure files and pause boundaries, popup language
switching and fonts, Firefox ESR 140.16 real content-script ECDH/SAS/message and
file round trips, and site checks at 320, 390, 768, 1280 and 1440 pixels.
Live Chrome two-account tests from 1.1.0 remain documented separately.

The Firefox package is unsigned. Load it temporarily through about:debugging;
permanent standard Firefox installation requires AMO signing.
