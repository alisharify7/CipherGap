# CipherGap 1.7.0 — 2026-10-07

The new Transfer tab exports all keys/settings or one chat to a password-encrypted
`.ciphergap` file. Import previews replacements, retains unrelated chats and
rejects malformed/damaged backups or active exchanges. Original-chat recovery
preserves personal trust records; partner transfer maps only the key to the
current conversation and marks it unverified.

Keys can also be shared with a locally generated QR, scanned with the camera,
read from an image, or pasted after another scanner reads them. QR carries a
plaintext secret: show it privately. Camera streams and QR canvases are cleared
when dismissed or hidden. All QR dependencies are bundled with their licenses.

The popup now has explicit Security, Files, Transfer, Settings and About (with the guide) tabs
with icons, keyboard navigation and RTL direction. The support link points to
https://www.coffeete.ir/alisharify7. Donation is optional.

Android 0.1.3 uses the same transfer core and popup, with native document saving
and camera permission limited to its trusted local key-scanner UI. Its separate
[Android release](https://github.com/alisharify7/CipherGap/releases/tag/android-v0.1.3)
provides a production-signed release APK with debugging disabled. It is distributed
directly, outside app stores. Export a password-encrypted backup before replacing
an older debug-signed installation; changing signatures requires uninstalling it.
See the browser and Android validation records for the exercised environments.

Both browser packages have `manifest.json` at the archive root. Chrome-family
browsers load the extracted folder in Developer mode. Firefox loads it through
`about:debugging`; permanent installation requires Mozilla signing.

Eitaa recognizes numeric and username chat URLs, and its channel history and
scrolling no longer cause unnecessary row/toolbar rewrites. Existing saved keys,
messages and CGPE attachments remain compatible.
