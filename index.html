  2. 02

    این شش رقم رو با هم چک کنین

    از وقتی درخواست فرستاده می‌شه، ۱۵ دقیقه وقت دارین؛ تایمر کنار پیام رو ببینین. کد شش‌رقمی رو توی یه تماس مطمئن یا حضوری با هم مقایسه کنین. اگه یکی بود، هر دوتون Codes match — verify رو بزنین. اگه یکی نبود، Codes don’t match رو بزنین.

    فقط فرستادن کد توی همین چت کافی نیست؛ از یه راه مطمئن هم چکش کنین تا هویت طرف مقابل تأیید بشه.

می‌خواین فایل‌ها خودکار باز بشن؟
گزینهٔ Receive files automatically رو برای هر چت جدا روشن کنین. تا وقتی همون چت بازه، فایل‌های جدید دریافت و رمزگشایی می‌شن.

گاهی یه استیکر بهتر از کلی حرفه. از دکمهٔ Emoji & stickers توی چت، شکلک رو به متن اضافه کنین و با Encrypt بفرستین. برای استیکر، تب Stickers رو باز کنین؛ یکی رو انتخاب کنین یا فایل خودتون رو بیارین. توی پیش‌نمایش پیام‌رسان فقط فایل رمز‌شده دیده می‌شه. دوست‌تون با Open توی همون پیام می‌بینتش و با Download نسخهٔ اصلی رو نگه می‌داره.

توی اندروید، شکلک رو از کیبورد یا منوی خود پیام‌رسان انتخاب کنین و با آیکون آبی CipherGap بفرستین. انتخابگر جداگانهٔ استیکر فقط توی افزونهٔ کامپیوتره؛ استیکرهای خود پیام‌رسان با CipherGap رمز نمی‌شن.

استیکر ثابت یا متحرک تا ۵ مگابایت، با فرمت‌های PNG، JPEG، WebP، GIF، AVIF و WebM می‌تونین بفرستین. هر دوتون افزونهٔ 1.5.0 به بالا یا برنامهٔ اندروید داشته باشین. استیکرهای منوی معمولی پیام‌رسان رمز نمی‌شن.

در هر بار انتخاب و برای هر فایل دریافتی، تا ۱۰۰ مگابایت پشتیبانی می‌شه. اگه دانلود مستقیم جواب نداد، فایل .cgpe رو از پیام‌رسان دانلود کنین و Choose downloaded file instead رو انتخاب کنین.

چت‌ها و کلیدهای شما به سرور CipherGap فرستاده نمی‌شن؛ پردازش روی دستگاه خودتونه. اما اطلاعاتی مثل اینکه با کی و چه وقت چت می‌کنین، پنهان نمی‌شه. وقتی متن داخل صفحه باز می‌شه، کد همون پیام‌رسان هم می‌تونه ببینتش. پس از دستگاهی استفاده کنین که بهش اعتماد دارین.

الان روی کدوم پیام‌رسان‌ها کار می‌کنه؟

بله وب، ایتا وب و تلگرام وب A روی اندروید و دسکتاپ کار می‌کنن. روبیکا و سروش پلاس هم با افزونهٔ دسکتاپ ۱.۶ آماده‌ان؛ نسخهٔ اندرویدشون هنوز آماده نیست. توی ایتا، تلگرام و سروش، چت با شناسهٔ عددی باز کنین؛ روبیکا مسیر #c= رو داره. واتساپ و تلگرام وب K هنوز پشتیبانی نمی‌شن.

دوستم CipherGap نداره؛ چی می‌بینه؟

زیر پیام رمز‌شده، راهنمای نصب و لینک GitHub و همین سایت رو می‌بینه. بعد از نصب نسخهٔ مناسب همین پیام‌رسان و تنظیم کلید مشترک، پیام باز می‌شه و راهنما دیگه توی چت نمایش داده نمی‌شه. برای روبیکا و سروش، افزونهٔ ۱.۶ به بالا لازمه. اگه CipherGap رو متوقف کنین، راهنما دوباره دیده می‌شه.

دوستم هم باید CipherGap داشته باشه؟

آره، ولی لازم نیست هر دوتون با یه دستگاه باشین. هر کدومتون برنامهٔ اندروید یا افزونهٔ کامپیوتر رو انتخاب کنین، توی همون چت کلید مشترک بسازین و کد شش‌رقمی رو از یه راه مطمئن مقایسه کنین.

همهٔ پیام‌ها خودشون رمز می‌شن؟

نه؛ برای متن، Encrypt یا آیکون آبی CipherGap توی اندروید رو بزنین. برای فایل هم از Encrypted file استفاده کنین. دکمه‌های ارسال متن و فایل خود پیام‌رسان، با CipherGap رمز نمی‌کنن.

اثر انگشت عوض شده یا کدها یکی نیستن؛ چی کار کنم؟

ممکنه بعد از تعویض دستگاه یا تبادل دوبارهٔ کلید، اثر انگشت عوض بشه. قبل از ادامه، از یه راه مطمئن هویت دوست‌تون رو چک کنین. اگه کدها فرق دارن، Codes don’t match رو بزنین و دوباره تبادل کلید کنین.

وقت تبادل کلید تموم شد؛ حالا چی؟

درخواست و کد تأیید بعد از ۱۵ دقیقه منقضی می‌شن؛ تایمر به صفر می‌رسه و کارت خاکستری می‌شه. یه درخواست تازه بفرستین و کد جدید رو مقایسه کنین. باز کردن دوبارهٔ صفحه، وقت درخواست قبلی رو تمدید نمی‌کنه و منقضی شدن درخواست هم کلیدهای قبلی رو پاک نمی‌کنه.

چطور CipherGap رو موقت خاموش کنم؟

توی Settings، گزینهٔ CipherGap enabled رو خاموش کنین تا توی همهٔ چت‌ها متوقف بشه. Enabled in this chat فقط همون چت رو متوقف می‌کنه؛ کلیدها هم پاک نمی‌شن. Pause chat داخل چت هم همین کار رو می‌کنه.

چرا یه پیام قدیمی باز نمی‌شه؟

برای باز کردن پیام، همون کلیدی لازمه که موقع ارسال داشتین. اگه کلید رو عوض یا پاک کنین، ممکنه پیام‌ها و فایل‌های قبلی با کلید جدید باز نشن. قبل از پاک کردن کلید، حواس‌تون به این موضوع باشه.

چرا فایل‌ها خودکار باز نمی‌شن؟

کلید چت و گزینهٔ Receive files automatically رو چک کنین. دریافت خودکار فقط برای فایل‌های جدیده، اون هم وقتی چت بازه. فایل‌های قبلی رو با Decrypt & view باز کنین؛ اگه دریافت مستقیم جواب نداد، فایل دانلودشده رو انتخاب کنین.

دکمه‌های افزونه نیستن؛ چی کار کنم؟

صفحهٔ پیام‌رسان رو رفرش کنین و چت رو باز کنین. چک کنین افزونه روشنه و اجازهٔ دسترسی به پیام‌رسان داره؛ فقط یه نسخهٔ CipherGap رو فعال نگه دارین. توی فایرفاکس هم بعد از بستن و باز کردن مرورگر، افزونهٔ موقت رو دوباره اضافه کنین.

توی خود برنامهٔ تلگرام یا بله هم کار می‌کنه؟

نه؛ CipherGap اندروید یه مرورگر برای نسخهٔ وب پیام‌رسان‌هاست و برنامه‌های اصلی رو تغییر نمی‌ده. روی کامپیوتر هم افزونه فقط توی صفحهٔ وب پیام‌رسان کار می‌کنه.

برای iPhone یا Safari هم دارین؟

فعلاً نسخهٔ iOS یا افزونهٔ Safari نداریم. برای اندروید APK رو بگیرین و برای لپ‌تاپ راهنمای Chrome یا Firefox رو دنبال کنین. اضافه کردن این سایت به صفحهٔ اصلی به شکل PWA، CipherGap رو داخل برنامه‌های پیام‌رسان فعال نمی‌کنه.

توی برنامه وارد شدم؛ چرا توی مرورگرم نیست؟

CipherGap مرورگر خودش رو داره و ورود Chrome یا Firefox رو وارد نمی‌کنه؛ باید داخل خود برنامه وارد بشین. فقط یه صفحهٔ پیام‌رسان فعاله و اگه پیام‌رسان رو عوض کنین، ممکنه لازم باشه تبادل کلید ناتمام رو از اول انجام بدین. تماس، دوربین و میکروفون هم توی این نسخه پشتیبانی نمی‌شن.

چرا برنامه سازگار نیست یا اعلان نمیاد؟

برای نصب، اندروید ۸ به بالا لازمه؛ برای رمزنگاری هم WebView باید اجرای جدا رو پشتیبانی کنه. اگه هشدار سازگاری می‌بینین، WebView رو از مسیر رسمی به‌روز کنین. برای اعلان‌ها، تنظیم و مجوزشون رو روشن کنین و برنامه و چت رو باز نگه دارین؛ اعلان پس‌زمینه نداریم.
